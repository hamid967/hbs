# نطاق Deno

يحتفظ هذا المجلد فقط بأتمتة أو أدوات Deno المخصصة مستقبلاً. لا يستخدم المشروع تطبيق Deno في وقت التشغيل؛ تطبيق HR HBS مبني على Node.js وReact وTypeScript، وتبقى فحوصه في `HBS Verification` وCI الخاص بالحزم Node.

يتحقق Workflow Deno من ملفات المصدر والاختبار الموجودة داخل هذا المجلد فقط. هذا يمنع استخدام Deno Linter على طبقة Node/TypeScript كاملة، حيث تختلف قواعد بيئة التشغيل مثل `process` وأدوات Node. عند إضافة أداة Deno فعلية، أضف مصدرها واختبارها هنا كي تُفحص تلقائياً.
