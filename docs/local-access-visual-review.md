# مراجعة بصرية لبوابة الوصول المحلي

تمت مراجعة لقطة اختبار Playwright لمسار `/login` على عرض هاتف 390 بكسل. تعرض اللقطة المشهد البصري الثلاثي الأبعاد في رأس الصفحة ثم حقلي بريد العمل وكلمة المرور وزر تسجيل الدخول دون تجاوز أفقي، وتبقى دعوة طلب الاشتراك مرئية أسفل النموذج.

المشهد مصمم كطبقات CSS ثلاثية الأبعاد خفيفة ولا يتضمن صوراً خارجية أو بيانات تشغيلية. الحركات البصرية محصورة ضمن تفضيل عدم تقليل الحركة، بينما يظل النموذج والنصوص والتباين مرئيين عند تفعيل تقليل الحركة. لا يتضمن المسار في هذه المراجعة رابطاً أو انتقالاً مرئياً إلى OAuth Manus.

هذه مراجعة واجهة لمسار غير موثّق فقط؛ لا تثبت إصدار دعوة فعلية أو جلسة محلية حية، لأن ذلك يبقى مشروطاً بتهيئة قاعدة تطوير محلية وقائمة الأصول المعتمدة.

## فحص المعاينة المستقلة

في 28 أغسطس 2026، استقرت معاينة الفرع المستقل على `/login` بعد التحميل، وظهر حقل كلمة المرور والنموذج والمشهد ثلاثي الأبعاد. أكّد فحص وحدة التحكم عدم وجود مخرجات خطأ، كما أثبت فحص DOM أن المسار الحالي هو `/login` وأن النموذج المحلي موجود. هذه المعاينة ليست نشرًا عامًا ولا تغيّر نسخة `main`.
