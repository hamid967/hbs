# شخصيات المحاكاة والتلميحات والتلخيص الذكي

## المنفذ

يتيح محاكي الموافقات الآن اختيار شخصية تجريبية محلية لكل دور من الموظف والمدير والوحدة المختصة. تظل هذه التعيينات أسماء عرض داخل مكوّن المحاكاة فقط؛ لا تنشئ مستخدمين أو حسابات أو ملفات موظفين أو جلسات، ولا تغير بيانات الأدوار الحقيقية.

يضيف الخط الزمني للأهداف تلميحاً يظهر عند تمرير المؤشر فوق الهدف، ويعرض نسبة التقدم وتاريخ الاستحقاق وحالة مجدول أو قريب أو متأخر. كما يتيح زر التلخيص الذكي لـHR والمسؤول طلب ملخص عربي موجز من بيانات الأهداف المفلترة التي يعيد الخادم تحميلها ضمن الشركة نفسها.

## حدود الذكاء الاصطناعي وOAuth

تصل خدمة التلخيص إلى نموذج خادمي فقط ولا تستدعيه الواجهة مباشرة. ترسل للخدمة حالة الهدف ونسبة التقدم وتاريخ الاستحقاق بعد تطبيق تصفية الشركة والقسم والتاريخ؛ لا ترسل أسماء الموظفين أو ملاحظات التقدم أو الوثائق. يطلب النظام من النموذج عدم اختلاق حقائق أو تقديم قرارات مالية أو قانونية أو تقييمات للموظفين.

لا تنشئ الشخصيات التجريبية أو التلخيص الذكي جلسات OAuth أو تثبت القبول الحي للموافقات. يظل ذلك اختباراً منفصلاً يعتمد على مستخدمين مفعّلين وجلسات مستقلة حقيقية.

## دليل التحقق

نجح `pnpm check` و`pnpm test` بعدد 133 اختباراً عبر 38 ملف اختبار، ونجح `pnpm build`. التحقق لم ينفذ نداء إنتاجياً إلى نموذج الذكاء الاصطناعي، لتجنب استهلاك غير ضروري ولأن المخرجات تعتمد على بيانات الشركة الحية عند طلب المسؤول.
