# دفعة المرحلة السابعة — الخط الزمني للأهداف

## المنفذ

تعرض لوحة الأهداف خطاً زمنياً للأهداف التي لها تاريخ مستهدف بعد تطبيق تصفية القسم والتاريخ الحالية. يرتب الخط الأهداف تصاعدياً حسب الاستحقاق ويعرض اسم الهدف وموظفه وتاريخ الاستحقاق ونسبة التقدم وحالة موجزة: مجدول أو قريب أو متأخر.

تستخدم الدفعة قائمة الأهداف المفلترة نفسها التي تعتمد عليها بطاقات المؤشرات والمعاينة والتصدير، لذلك لا تضيف استعلاماً جديداً أو نطاق وصول جديداً. يظل العرض محصوراً في HR والمسؤول عبر راوتر الأهداف الحالي.

## الحدود المتعمدة

لا ينشئ الخط الزمني تذكيرات أو رسائل أو مهام أو قرارات تلقائية. ولا يثبت أداء الموظف أو يؤثر في التقييم أو الرواتب. الأهداف بلا تاريخ مستهدف لا تظهر في الخط وتبقى متاحة في القائمة الأساسية.

## دليل التحقق

نجح `pnpm check` و`pnpm test` بعدد 133 اختباراً عبر 38 ملف اختبار، ونجح `pnpm build`. تحذيرات حجم الحزم الكبيرة بقيت دين أداء معروفاً وليست فشلاً في البناء.
