# دفعة المرحلة السابعة — لوحة تقدم الأهداف والمتابعة

## المنفذ

تضيف صفحة الأهداف لوحة مرئية تعرض عدد الأهداف النشطة والمكتملة ومتوسط التقدم وعدد الأهداف التي تحتاج متابعة. تُحسب المؤشرات من الأهداف المتاحة فعلياً داخل الشركة، ولا تستخدم بيانات مولّدة أو درجات أداء افتراضية.

تعرض اللوحة الأهداف المتأخرة أو القريبة خلال سبعة أيام كتذكير إرشادي داخل الصفحة نفسها. يستند التأخر إلى تاريخ الهدف المستهدف وحالة الهدف الحالية. يظل صندوق العمل مقتصراً على عرض أهداف الحساب نفسه، بينما تبقى إدارة الأهداف وتقدمها ضمن صلاحيات HR والمسؤول.

## الحدود المتعمدة

المتابعة المعروضة ليست إشعاراً تلقائياً ولا رسالة بريد ولا مهمة إلزامية، ولا تحدث حالة الهدف أو تسجل قراراً أو يترتب عليها أثر مالي أو وظيفي. أي تشغيل دوري أو تذكير خارجي يحتاج سياسة زمنية معتمدة ومصمم مهام منفصل.

## دليل التحقق

نجح `pnpm check`، ونجح `pnpm test` بعدد 131 اختباراً عبر 37 ملف اختبار، ونجح `pnpm build`. تغطي الاختبارات عزل أهداف صندوق العمل بالهوية والشركة، وتثبت اللوحة أن بياناتها مصدرها أهداف الشركة الموجودة فقط.
