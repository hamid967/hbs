# مراجعة دليل الموظفين والأقسام

تمت معاينة صفحة دليل الموظفين على سطح المكتب والهاتف بعد إضافة وحدة الأقسام والملفات الوظيفية. أظهرت المعاينة المتجاوبة عنوان الوحدة، وبيانات الملف الأساسية، وزر إدارة الملف، مع المحافظة على اتجاه RTL. تتحقق اختبارات الخادم من تقييد الدليل بالأدوار المخولة، وإنشاء القسم داخل الشركة، وحفظ الملف ضمن نطاق الشركة الحالي.
