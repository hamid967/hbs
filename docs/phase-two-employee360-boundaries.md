# دفعة المرحلة الثانية — ملف الموظف 360

## المنفذ

تضيف هذه الدفعة حقول **موقع العمل** و**جهة اتصال الطوارئ** إلى ملف الموظف. يحفظ موقع العمل ضمن `employeeProfiles` لدعم العرض والتحليل التشغيلي. أما جهة اتصال الطوارئ فتحفظ في جدول مستقل معزول بالشركة، ولا تُقرأ أو تُحدّث إلا بواسطة HR والمسؤول.

يُسجل تحديث جهة الطوارئ كحدث `profile_updated` موجز في دورة حياة الموظف من دون نسخ الاسم أو صلة القرابة أو رقم الهاتف إلى السجل. يختبر الخادم سياق الشركة وصلاحية الدور قبل القراءة أو الحفظ.

## ما بقي خارج النطاق

لا تتضمن الدفعة عقود عمل أو إصدارات عقود أو مستندات أو توقيعاً أو حساباً بنكياً أو توابع أو رواتب. تستلزم هذه المجالات سياسة تصنيف واحتفاظ بالبيانات، وتخزيناً آمناً للملفات، ومراجعة امتثال ومالك نطاق قبل البدء.

## دليل التحقق

نجح `pnpm check`، ونجح `pnpm test` بعدد 117 اختباراً عبر 33 ملفاً، ونجح `pnpm build`. تحذيرات حجم الحزم الكبيرة بقيت موثقة كعمل أداء لاحق.
