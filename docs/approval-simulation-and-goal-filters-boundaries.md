# محاكي الموافقات وتصفية الأهداف

## المنفذ

أضيف محاكي واجهي غير إنتاجي لمسار الموافقة: إرسال افتراضي من الموظف، ثم قرار المدير المباشر، ثم قرار الوحدة المختصة وفق نوع الطلب، ثم الاكتمال. يعتمد المحاكي على قواعد تسلسل ثابتة ومختبرة، ولا يقرأ طلبات الشركة ولا ينشئ حسابات أو جلسات أو مهام موافقة في قاعدة البيانات.

كما أضيفت إلى لوحة الأهداف تصفية حسب القسم وتاريخ الهدف المستهدف. تستخدم التصفية الموظفين والأقسام المحمّلة بالفعل ضمن استعلام HR/Admin المقيد بالشركة، ولا توسع الاستعلام أو نطاق العرض إلى شركات أو أدوار أخرى.

## الحدود المتعمدة

المحاكي ليس جلسة موظف أو مدير أو وحدة مختصة، ولا ينتحل OAuth أو يثبت التفويض الحي أو الإشعارات أو ملفات الارتباط. يظل قبول الموافقات الحي رهيناً بجلسات مستقلة ومفعلة للأدوار الثلاثة داخل الشركة نفسها. كذلك تبقى تصفية الأهداف أداة متابعة داخلية ولا تنشئ إشعارات أو قرارات مالية أو وظيفية.

## دليل التحقق

نجح `pnpm check`، ونجح `pnpm test` بعدد 133 اختباراً عبر 38 ملف اختبار، ونجح `pnpm build`. تغطي اختبارات المحاكي ترتيب المدير قبل الوحدة واختيار الوحدة الملائمة لنوع الطلب.
