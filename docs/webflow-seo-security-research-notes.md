# ملاحظات بحث SEO والأمن والصيانة لموقع Webflow

| المصدر | المعلومة المستخدمة | أثرها على التقويم والدليل |
|---|---|---|
| Webflow University — SEO checklist | تغطي قائمة Webflow بنية الموقع والاستجابة والكلمات المفتاحية وتسلسل العناوين ووسوم HTML والتنقل والروابط وmetadata وOpen Graph والنص البديل وSSL وSearch Console وsitemap. | تتحول إلى فحوص شهرية وربع سنوية، مع قائمة فحص عند كل تغيير عنوان أو رابط أو قالب CMS. |
| Webflow University — SEO checklist | توصي Webflow بروابط قصيرة وصفية وباستخدام 301 عند تغيير URL، كما تذكر عناوين meta فريدة ووصفاً لكل صفحة وإعدادات Open Graph لكل صفحة. | تدخل مراجعة redirects وmetadata وOpen Graph في فحوص الإصدار الشهري. |
| Google Search Central — Core Web Vitals | تشرح Google أن Core Web Vitals تقيس تجربة المستخدم الحقيقية للأداء والتحميل والتفاعل والاستقرار البصري. | تدخل مراجعة شهرية من Search Console وLighthouse ضمن لوحة الأداء. |
| Webflow Help — Site Activity log | يتيح سجل النشاط تتبع تغييرات الموقع وحالة التغييرات. | يراجع أسبوعياً وبعد كل حادث ضمن الحوكمة الأمنية. |
| Google Search Central — Core Web Vitals | توصي Google بهدف LCP خلال 2.5 ثانية، وINP أقل من 200ms، وCLS أقل من 0.1 لتجربة مستخدم جيدة، مع مراجعة التقرير في Search Console. | تدخل هذه الحدود في مراجعة الأداء الشهرية وفي فحص ما قبل الإطلاق للتغييرات الكبيرة. |
| Webflow Help — Site Activity log | يتتبع السجل تغييرات الصفحات وCMS والمكونات والمتغيرات والكود المخصص والنسخ الاحتياطية والنشر، ويعرض الفاعل والوقت وحالة النشر؛ وهو متاح لعملاء Enterprise وشركائه. | يُستخدم عند توفره لمراجعة أسبوعية للتغييرات غير المنشورة والمنشورة، مع بديل سجل تغيير يدوي إن لم تكن الخطة مؤهلة. |
