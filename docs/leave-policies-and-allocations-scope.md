# نطاق سياسات الإجازة والأرصدة الداخلية

تضيف هذه الدفعة نموذجاً تشغيلياً داخلياً لإدارة سياسات الإجازة وتخصيص أرصدة الموظفين داخل الشركة نفسها. لا تُنقل أي ملفات أو بنية أو واجهة من Frappe HRMS؛ كانت نتائج التدقيق مرجعاً وظيفياً عاماً فقط.

| المجال | قرار الدفعة |
| --- | --- |
| الأنواع | سنوية، مرضية، وطارئة فقط. |
| السياسة | ينشئ HR أو المسؤول سياسة فعالة واحدة لكل نوع داخل شركته، بعنوان وعدد أيام مرجعيين. |
| التخصيص | يخصص HR أو المسؤول رصيداً سنوياً صريحاً لموظف فعّال وسياسة من الشركة نفسها. |
| الرصيد | يعرض للموظف رصيده المخصص والأيام المعتمدة والمعلّقة والمتبقية للسنة الخاصة بتاريخ الطلب. |
| الطلب | يرفض الطلب الذي يعبر سنة تقويمية، أو يتداخل مع طلب إجازة قائم غير مرفوض، أو يتجاوز الرصيد المتاح بعد احتساب الطلبات المعلّقة والمعتمدة. |
| الصلاحيات | HR والمسؤول يديران السياسات والتخصيصات؛ الموظف يقرأ رصيده الشخصي فقط؛ المدير والوحدة الحكومية لا يقرآن أرصدة الفريق. |
| العزل | كل قراءة وكتابة تتحقق من `companyId` في الخادم ومن انتماء الموظف والسياسة والتخصيص للشركة نفسها. |

هذه الأرصدة ليست استحقاقات نظامية أو كشف رواتب أو معادلات استحقاق أو تسوية مالية. لا تشمل الدفعة مرفقات، تحويلات نقدية، تكاملات حكومية، أو تفسيراً قانونياً.
