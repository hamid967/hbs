# مراجعة الأمر التنفيذي المرفق ومواءمته مع HBS

## القرار المعماري

يوصي HBS بمسار **إعادة التنفيذ الأصلي داخل HBS** للدفعات التشغيلية الحالية. استُخدم Frappe HRMS مرجعاً وظيفياً فقط في تدقيق سابق عند المرجع `03b65e8`، وثُبتت رخصته GPLv3. لذلك لا تنقل HBS ملفات Python أو DocTypes أو واجهة أو أصول Frappe، ولا تشغّل خدمة Frappe أو تكامل REST/Webhooks في هذا النطاق. يظل تشغيله كخدمة مستقلة خياراً مؤجلاً يحتاج قرار مالك ومراجعة ترخيص وتشغيل منفصلة.

| مطلب الأمر | حالة HBS الحالية | قرار التنفيذ |
| --- | --- | --- |
| RTL وReact/tRPC/Express/Drizzle/MySQL | موجودة ومستخدمة | تستمر كما هي. |
| ملف الموظف 360 | ملف وظيفي، رقم موظف، مسمى نصي، قسم، منطقة، موقع عمل، مدير مباشر، حالة، جهة طوارئ، وخط زمني | مكتمل كأساس داخلي؛ تُستكمل المسميات المنظمة كتحسين متوافق مع البيانات الحالية. |
| الهيكل التنظيمي | أقسام مملوكة للشركة وعزل خادمي | مكتمل؛ لا يوجد حالياً كيان مستقل للمسميات الوظيفية. |
| العقود والوثائق | سجلات عقود تشغيلية، بيانات وثيقة، تخزين خارجي، معاينة PDF/PNG/JPEG قبل الحفظ، وصلاحيات HR/Admin | مكتمل ضمن النطاق التشغيلي، بلا توقيع إلكتروني أو أثر قانوني. |
| الإجازات | أنواع، موافقات، سياسات وتخصيص أرصدة داخلية | مكتمل كدفعة داخلية؛ لا استحقاق شهري أو ترحيل أو قاعدة سعودية مفترضة. |
| الحضور والورديات | تسجيل داخلي وسياسات وورديات وصفية | لا أجهزة، GPS، بصمة، أو اتصال خارجي. |
| الرواتب/WPS/GOSI | غير منفذة | بوابة مستقلة تتطلب مصادر رسمية واعتمادات بشرية؛ لا تُنفذ في هذه الدفعة. |
| العلاقات الحكومية | طلبات عامة ومسار موافقات | لا معاملات حكومية أو تكاملات حية بلا API واعتماد رسمي. |
| القبول الحي للموافقات | اختبارات آلية موسعة، وجلسة مسؤول وحساب علاقات حكومية مفعّلان | يبقى مفتوحاً حتى توفر جلستي موظف ومدير مباشر مستقلتين فعلياً. |

## الوحدة الأولى من الأمر

تتحقق معظم عناصر «ملف الموظف 360 + الهيكل التنظيمي + العقود والوثائق» داخل HBS بالفعل. التحسين الأصلي التالي الآمن هو **إدارة مسميات وظيفية مملوكة للشركة**، مع إبقاء حقل المسمى النصي الحالي متوافقاً مع البيانات الموجودة وعدم إجراء حذف أو تحويل تلقائي للبيانات. يرتبط هذا الكيان اختيارياً بملف الموظف، ويُدار من HR/Admin ضمن الشركة نفسها.

## حدود واستبعادات صريحة

لا تعني هذه المراجعة امتثالاً قانونياً أو سعودياً، ولا تخول احتساب الرواتب أو مزايا الإجازات أو مكافأة نهاية الخدمة أو التأمينات أو حماية الأجور. كما لا تُنشأ حسابات OAuth اختبارية ولا تُتخذ قرارات على طلبات قائمة من أجل الاختبار.

## خطة التغيير والرجوع

ستضاف الجداول والحقول الجديدة بإضافات توافقية فقط، مع ترحيل Drizzle مُراجع قبل التطبيق. يبقى حقل المسمى النصي الحالي ومحتوى العقود والوثائق كما هو. الرجوع الآمن هو التوقف عن استخدام الكيان المنظم في الواجهة مع بقاء الحقول السابقة والبيانات الحالية سليمة؛ لا تُنفذ عمليات حذف أو تحويل بيانات آلي.
