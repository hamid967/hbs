# ملاحظات التصورات المرئية لمشروع Webflow

تعرض الرسوم الثلاثة توزيع تكلفة العمل وجدول التنفيذ من النموذج التخطيطي القابل للتعديل. تستند إلى أسعار الساعات وساعات العمل الافتراضية في نموذج الميزانية، ولذلك يجب إعادة توليدها بعد إدخال عروض الموردين أو تغيير نطاق المشروع.

| المؤشر | القيمة المعروضة |
|---|---:|
| تكلفة العمل الأساسية | 40,600 SAR |
| احتياطي المخاطر (12%) | 4,872 SAR |
| الإجمالي التقديري قبل الضريبة | 45,472 SAR |
| مدة التنفيذ | 30 يوم عمل |
| المدة بالأسابيع | 6.0 أسابيع على أساس خمسة أيام عمل أسبوعياً |

تشمل الملفات: `webflow_cost_distribution.png` لتوزيع التكلفة، و`webflow_timeline_gantt.png` للتسلسل الزمني، و`webflow_budget_timeline_dashboard.png` للوحة الموجزة. لا تشمل الأرقام ضريبة القيمة المضافة أو رسوم الموردين غير المدخلة في ورقة الافتراضات.
