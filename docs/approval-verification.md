# توثيق التحقق من مسار الموافقات

يوضح هذا المستند ما تم التحقق منه آلياً لمسار الموافقات متعدد المراحل، وما يبقى للتحقق الحي عند توفر جلسة مصادقة صالحة. لا يستخدم هذا التحقق بيانات إنتاجية مصطنعة.

| نطاق التحقق | الدليل الآلي الحالي | الحالة |
|---|---|---|
| إسناد المرحلة الأولى | اختبار صندوق المدير يقيد المهمة بهوية المدير المعيّن | مكتمل |
| انتقال المرحلة الثانية | اختبار خطة انتقال موحدة يثبت المهمة الجديدة وحالة الطلب وسجل المرحلة وإشعار الوحدة ضمن الشركة | مكتمل |
| خصوصية الموظف | اختبار تنقية السجل والمراحل يحجب ملاحظات القرار ويُبقي الحالة والتاريخ | مكتمل |
| عرض المسار | فحص الأنواع ومراجعة واجهة تفاصيل الطلب وصندوق الموافقات | مكتمل |
| دورة حية متعددة الحسابات | تتطلب جلسات OAuth صالحة للموظف والمدير والوحدة | مؤجل عند تجدد الجلسة |

> عند تجدد المصادقة، يُعاد اختبار إنشاء طلب، قرار المدير، وصول إشعار الوحدة، قرار الوحدة، ثم وصول إشعار القرار إلى الموظف، دون تعديل البيانات يدوياً.

## إغلاق المرحلة دون متصفح

بناءً على توجيه المالك، أُغلقت مرحلة التطوير والاختبار الآلي دون استخدام المتصفح. يغطي اختبار التكامل المعزول الآن إنشاء الطلب، تنبيه المدير المعيّن، إنشاء مهمة المرحلة الثانية، تنبيه الوحدة المطابقة، وسجل المرحلة، ثم تنبيه الموظف بالقرار النهائي. يبقى التحقق المرئي متعدد الحسابات نشاط قبول لاحقاً عند توفير جلسات دخول صالحة، ولا يُعد منفذاً في هذا الإغلاق.
