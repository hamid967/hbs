# مركز الإشعارات ومعاينة تقارير الأهداف

## المنفذ

يعرض مركز الإشعارات الآن ملخصاً لإشعارات الموافقات غير المقروءة التي تتطلب إجراءً، وملخصاً لقرارات الطلبات المكتملة للحساب الحالي. يعتمد التصنيف على نوع الإشعار المخزن (`approval_required` أو `request_decision`) ولا يضيف اشتراكاً خارجياً أو بثاً فورياً بين المتصفحات.

تضيف لوحة الأهداف نافذة معاينة لتقرير الصفوف المفلترة. يستطيع HR والمسؤول اختيار أعمدة الهدف والموظف والقسم والحالة والتقدم والتاريخ المستهدف، ثم تنزيل نفس الأعمدة المحددة إلى CSV أو PDF. يعرض PDF ملخصاً لعدد الأهداف والمكتملة ومتوسط التقدم وشريطاً مرئياً للنسبة قبل قائمة الصفوف.

## الحدود المتعمدة

الإشعارات تظهر عند فتح التطبيق أو تحديث الاستعلام ولا تمثل اتصالاً فورياً عبر WebSocket أو رسالة بريد أو دفعاً خارجياً. التصدير يستخدم البيانات المفلترة المتاحة للحساب ضمن الشركة فقط، ولا يحفظ الملف على الخادم أو يشارك البيانات مع خدمة خارجية.

## دليل التحقق

نجح `pnpm check` و`pnpm test` بعدد 133 اختباراً عبر 38 ملف اختبار، ونجح `pnpm build`. يبقى تحذير حجم الحزم الكبيرة دين أداء معروفاً وليس فشلاً في البناء.
