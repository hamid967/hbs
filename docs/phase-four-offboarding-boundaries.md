# دفعة المرحلة الرابعة — إنهاء الخدمة الداخلي

## المنفذ

تضيف هذه الدفعة حالة إنهاء خدمة واحدة لكل موظف في الشركة وقائمة تحقق تشغيلية افتراضية لمراجعة سجلات العقود والوثائق والوصول والتسليم الداخلي. تعرض الصفحة عدد العقود والوثائق المرتبطة بالموظف، لكنها لا تنقل الملفات أو تعدلها. تحفظ مهام القائمة وتغييراتها ضمن الشركة، ولا يديرها إلا HR أو المسؤول.

يُسجل بدء القائمة واكتمالها كأحداث موجزة في دورة حياة الموظف. لا تُغير القائمة حالة الحساب أو حسابات الوصول أو حالة التوظيف تلقائياً؛ تبقى تلك العمليات بقرارات وواجهات مخولة مستقلة.

## الحدود المتعمدة

لا تتضمن هذه الدفعة مكافأة نهاية خدمة أو رواتب أو تسويات أو حسابات مالية أو نصوصاً قانونية أو إنذارات أو إيقاف وصول فعلي. لا ينبغي استخدام قائمة التحقق كبديل للمراجعة القانونية أو سياسة الموارد البشرية المعتمدة.

## دليل التحقق

نجح `pnpm check`، ونجح `pnpm test` بعدد 127 اختباراً عبر 36 ملف اختبار، ونجح `pnpm build`. تغطي اختبارات الراوتر عزل الشركة وصلاحيات HR/Admin وبدء القائمة وتسجيل حدث اكتمالها مرة واحدة فقط.
