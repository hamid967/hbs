# خطة تطوير Webflow للموقع التسويقي | حلول الغد

## قرار المعمارية

يُستخدم **Webflow** للموقع التسويقي العام والمحتوى القابل للتحرير، بينما يبقى تطبيق HR HBS الداخلي على React وtRPC وMySQL. هذا الفصل يحافظ على عزل الشركات والصلاحيات وسير الموافقات داخل التطبيق، ويعطي فريق التسويق قدرة مستقلة على تحرير الصفحات والمقالات والتحويلات من دون تعديل منطق المنتج.

| المجال | Webflow | تطبيق HR HBS |
|---|---|---|
| الجمهور | زائر ومهتم وعميل محتمل | موظف ومدير وHR والعلاقات الحكومية |
| الوظيفة | تعريف القيمة، المحتوى، طلب العرض، التحويل | الطلبات والموافقات والموظفون والتقارير والصلاحيات |
| مصدر البيانات | CMS ومحتوى تسويقي معتمد | MySQL ضمن `companyId` وصلاحيات الدور |
| الدخول | لا دخول تشغيلي؛ روابط CTA فقط | OAuth وصلاحيات ووحدات وصول |
| النشر | تحرير تسويقي مضبوط ومراجعة SEO | إصدار تقني واختبارات ونقطة استعادة |

> لا يُنقل أي نموذج تشغيل أو بيانات موظفين أو منطق موافقات إلى Webflow. يقتصر التكامل على تحويل العميل المحتمل وروابط الدخول والتتبع المصرح به.

## نظام التصميم والتنفيذ في Webflow

يعتمد الموقع نفس روح هوية حلول الغد، لكن ضمن نظام مكونات قابل للصيانة: اتجاه RTL، تباين مقروء، أخضر داكن للعناصر الحاكمة، ذهبي محدود للإبراز، ومساحة كريمية هادئة للمحتوى. تُبنى المكونات عبر Webflow Components وVariables، ولا يُقبل نسخ أنماط أو محتوى من مواقع مرجعية.

| طبقة البناء | المكونات |
|---|---|
| التأسيس | Variables، الخطوط، RTL، شبكة المسافات، ألوان التباين، حالات التركيز والحركة المختزلة |
| التنقل | رأس، قائمة هاتف، تذييل، شريط CTA، مسار رجوع |
| التحويل | Hero، وحدات قيمة، مقارنة قدرات، إثباتات معتمدة، CTA، نموذج طلب عرض |
| المحتوى | قالب مورد، قالب حل، قالب ميزة، CTA سياقي، أسئلة شائعة |
| الجودة | عناصر عنوان صحيحة، نص بديل، حالة خطأ النموذج، قياس وتحميل سريع |

| التحليلات | قياس التحويل ومصدر الزيارة | أحداث موافقة ومحدودة البيانات | اعتماد سياسة القياس والخصوصية |

## الحوكمة والإطلاق

لا ينشر فريق التسويق محتوى جديداً بلا مالك ومراجع وتاريخ مراجعة. لا تُضاف شهادات أو تقييمات أو قصص عملاء بلا موافقة ودليل. ويُراجع كل نموذج أو Webhook مع مالك البيانات قبل النشر. عند رغبة الفريق في الإدارة المباشرة لموقع Webflow، يُؤمَّن اتصال منفصل للموقع ونحدد أولاً: الموقع المستهدف، أعضاء التحرير، وسياسة النشر.

## قرار البدء

تبدأ خطة Webflow عند اعتماد مالك تسويق للمحتوى، وتحديد ما إذا كان نموذج طلب العرض يرسل إلى CRM أو إلى نظام داخلي، وتثبيت النطاق العام للموقع. بعد ذلك يمكن تشغيل مرحلتي التصميم والصفحات بالتوازي، بينما يبقى أي تكامل خارجي مقيداً ببيانات اعتماد معتمدة ومخزنة بأمان.
