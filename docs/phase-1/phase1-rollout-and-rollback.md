## الترحيلات

تتضمن السلسلة ترحيلين إضافيين مضافين فقط إلى الكود ولم يُطبّقا عبر هذا البرنامج على قاعدة بيانات مشتركة.

| الترحيل | ما يغيره | شرط التطبيق |
|---|---|---|
| `0040_lazy_guardian.sql` | يضيف الجداول التنظيمية وعلاقاتها وفهارسها. | بعد دمج PR #22 ومراجعة SQL في بيئة staging بمخطط مماثل. |
| `0041_jazzy_cloak.sql` | يضيف القيمة `document` إلى enum فئة سجل التدقيق. | بعد دمج PR #24 والتأكد من وجود `auditEvents` بالشكل المتوقع. |

يُنشأ **نسخة احتياطية قابلة للاستعادة** من مزود قاعدة البيانات قبل أي تطبيق. بعد ذلك يطبق فريق البيئة الترحيلات بالترتيب الرقمي، ويتحقق من وجود الجداول والفهارس وقيمة enum الجديدة، ثم يشغل `pnpm check` و`pnpm test` و`pnpm build` من المرجع المدمج. لا تُطبق الترحيلات من مساحة عمل محلية عشوائياً ولا تُنفذ أي عملية حذف أو خفض مخطط ضمن هذا البرنامج.

> الاستعادة من قاعدة البيانات عملية خاصة بالبيئة والبيانات؛ لا تعيد Git وحده مخططاً أو سجلات موجودة. لذا تكون نقطة الاستعادة الفعلية هي النسخة الاحتياطية التي أُنشئت قبل تطبيق SQL، بينما تعيد مراجعة Git فقط كود التطبيق إلى إصدار سابق.

## فحوص ما بعد الدمج

| المجال | فحص القبول | النتيجة المتوقعة |
|---|---|---|
| عزل الشركة | يحاول مستخدم من الشركة A التعامل مع معرف موظف أو وثيقة من الشركة B. | لا يسترجع المورد ولا يصدر رابط تخزين. |
| دليل الموظفين | يفتح المدير قائمة الفريق. | يرى نفسه ومرؤوسيه المباشرين فقط، بلا بريد أو `openId` أو رقم موظف أو تاريخ انضمام للمرؤوس. |
| الهيكل التنظيمي | ينشئ مسؤول وحدة أو فريقاً ضمن الشركة ويعين مرجعاً صالحاً. | تحفظ العلاقة المقيّدة بالشركة؛ يرفض المرجع الغريب أو الدورة الهرمية. |
| الوثائق | يفتح HR وثيقة ضمن الشركة. | يصدر الرابط بعد التفويض فقط، ويضاف حدث تدقيق موجز بالفئة `document`. |
| سجل التدقيق | يختار المسؤول فئة من الواجهة. | لا يحمّل إلا أحدث 25 حدثاً للفئة والشركة المحددتين، وتظل أدوار غير المسؤول محجوبة. |
| OAuth الحي | لا يُختبر ضمن دمج هذه السلسلة. | يبقى معلقاً حتى تتوفر الجلسات الفعلية الثلاثة المعتمدة. |

## مسار الاستعادة

إذا أخفق التحقق في staging، توقف عملية الطرح ولا تنقل التغيير إلى إنتاج. يعاد التطبيق إلى صورة قاعدة البيانات التي أُخذت قبل الترحيل، وتستخدم نقطة Git المعتمدة قبل PR المتسبب لاستعادة كود التطبيق في بيئة الاختبار. يوثق العطل ومعرّف الترحيل وحالة البيانات قبل إنشاء إصلاح منفصل؛ لا يعالج بإخفاء واجهة أو بإضافة استثناء يتجاوز السياسة الخادمية.

## حدود البرنامج

لا تضيف هذه الدفعات أرقام هوية وطنية، أو بيانات تعويضات، أو توقيعاً إلكترونياً، أو تكاملات حكومية، أو ادعاء امتثال قانوني. كما لا تنشئ حسابات OAuth أو تغير أدواراً أو علاقات بغرض قبول حي. تظل مراجعة الحوكمة القانونية والبيانات الاحتياطية الحقيقية وموافقات مالك البيئة مسارات تشغيلية مستقلة.
