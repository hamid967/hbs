# توحيد مهام إنهاء الخدمة في صندوق العمل

## المنفذ

يعرض صندوق العمل مهام إنهاء الخدمة المفتوحة لـHR والمسؤول فقط. تُحمّل المهام من سجلات الشركة نفسها، وتعرض تسمية المهمة واسم الموظف المرتبط مع رابط مباشر إلى صفحة إنهاء الخدمة. لا تظهر هذه البطاقة للمدير أو الموظف أو وحدة العلاقات الحكومية.

يجمع الصندوق الآن عناصر الحساب الشخصية، مثل الإشعارات والموافقات والتدريب والأهداف، مع التزامات HR/Admin التشغيلية المحددة. يبقى تعديل مهام الإنهاء محصوراً في صفحة إنهاء الخدمة وإجراءاتها المخولة.

## الحدود المتعمدة

لا تغير البطاقة حالة مهمة أو إنهاء خدمة، ولا ترسل تذكيراً أو تعطي صلاحية وصول أو تحتسب تسوية. تظل قائمة الإنهاء داخلية وغير قانونية وغير مالية.

## دليل التحقق

نجح `pnpm check` و`pnpm test` بعدد 133 اختباراً عبر 38 ملف اختبار، ونجح `pnpm build`.
