# تدقيق وظيفي مرجعي: Frappe HRMS وHBS

## الغرض والمنهج

استُخدم Frappe HRMS كمرجع لوظائف HRMS فقط، بعد فحص نسخة مرجعية عند `03b65e8` وترخيصها GPL v3. لم تُنسخ ملفات أو وحدات أو واجهات إلى HBS، ولن يدخل كود GPL إلى مستودع HBS. هذا التدقيق يعيد صياغة متطلبات عامة في مصطلحات HBS وبنيتها الحالية، وليس تحليلاً قانونياً للترخيص.

## المقارنة

| المجال المرجعي | حالة HBS المثبتة | الدفعة الأصلية المقترحة | بوابة/حد |
|---|---|---|---|
| ملف الموظف ودورة الحياة | ملفات، موقع عمل، جهة طوارئ، عقود تشغيلية، وثائق، أهداف، إنهاء خدمة | مكتمل داخلياً كقاعدة | العقود القانونية والتوقيع يحتاجان سياسة مستقلة |
| التوظيف والتهيئة | شواغر ومرشحون ومقابلات وعروض وقوالب تهيئة | تحويل المرشح إلى موظف بعد سياسة الهوية | لا يُنشأ حساب OAuth تلقائياً |
| الإجازات | أنواع محدودة وطلبات وموافقات | سياسات إجازة وتخصيص/رصيد داخلي قابل للاختبار | قواعد الاستحقاق السعودية تحتاج مصدر وسياسة معتمدة |
| الحضور والورديات | تسجيل داخلي وسياسات وورديات وصفية | تصحيح حضور وموافقاته بعد تحديد سياسة العمل | لا أجهزة بصمة أو GPS أو تكامل خارجي |
| المصروفات | طلبات سفر وتشغيل بعملة SAR | تصنيفات وسياسات ومراجعة بلا محاسبة | الفواتير/OCR والتصدير المحاسبي بوابات منفصلة |
| الأداء والتدريب | أهداف وتقدم وتدريب ولوحات مديرين | يبنى لاحقاً تقييم رسمي بعد سياسة عدالة واحتفاظ | لا تقييمات/قرارات مالية رسمية حالياً |
| الرواتب | غير منفذ | تحليل مصادر رسمية وقواعد قابلة للاختبار أولاً | لا معادلات أو WPS/GOSI بلا مصادر واعتمادات |
| العلاقات الحكومية | طلبات وعلاقات حكومية عامة | سجل امتثال داخلي ومواعيد يدوية بعد سياسة بيانات | لا ادعاء API حي أو تكامل رسمي |

## الدفعة الأصلية المختارة

تختار الدفعة التالية **سياسات الإجازة والتخصيص الداخلي للأرصدة** لأنها تبني على أنواع الإجازة والطلبات وسير الموافقات الموجودة، ولا تتطلب رواتب أو أجهزة أو APIs حكومية. ستصمم كجداول HBS أصلية مع عزل الشركة، واختبارات لقواعد الرصيد، وتبقى قواعد الاستحقاق سياسة الشركة لا قاعدة سعودية مفترضة.

## حدود المصدر

لا يسمح هذا التدقيق بنقل ملفات Python أو DocTypes أو واجهة Frappe أو شعارها إلى HBS. وإذا اختير مستقبلاً تشغيل Frappe كخدمة مستقلة، فيجب عزله في مستودع/خدمة منفصلة مع الترخيص وإشعارات الحقوق وسجل تغيير ومراجعة قانونية قبل أي توزيع أو تكامل.
