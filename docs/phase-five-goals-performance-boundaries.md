# دفعة المرحلة الخامسة — الأهداف والأداء الداخلي

## المنفذ

تضيف هذه الدفعة أهدافاً تشغيلية مرتبطة بالموظف وتحديثات تقدم من صفر إلى مئة. يمكن ربط تحديث التقدم بمسار تدريب مملوك للشركة، وهو ربط سياقي يساعد فريق HR على متابعة التطوير الداخلي فقط. تُحفظ الأهداف والتحديثات ضمن الشركة، ولا يديرها إلا HR أو المسؤول.

يسجل إنشاء الهدف وتحديث التقدم كحدث موجز في دورة حياة الموظف دون نسخ عنوان الهدف أو الوصف أو الملاحظة إلى سجل دورة الحياة. لا يفتح ذلك أي صلاحية جديدة للمدير أو الموظف أو وحدة العلاقات الحكومية.

## الحدود المتعمدة

لا تمثل الأهداف تقييماً للأداء الوظيفي أو قرار ترقية أو جزاء أو تسوية أو أثرًا مالياً. لا تتضمن الدفعة درجات أو معايرة أو مراجعات 360 أو رواتب أو توصيات قانونية. تتطلب أي توسعة إلى سياسة تقييم رسمية اعتماداً مستقلاً لمعايير العدالة والخصوصية والاحتفاظ بالبيانات.

## دليل التحقق

نجح `pnpm check`، ونجح `pnpm test` بعدد 131 اختباراً عبر 37 ملف اختبار، ونجح `pnpm build`. تغطي اختبارات الراوتر حصر الإدارة في HR/Admin وعزل الشركة وإنشاء الهدف وتحديث التقدم المرتبط اختيارياً بالتدريب.
