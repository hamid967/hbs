# مراجعة صلاحيات الوحدات

تمت مراجعة تحميل مساري إدارة الحسابات ومركز العمليات بعد ربطهما بصلاحيات الوحدات. ظهرت واجهات التحميل الأولية في جلسة المعاينة قبل اكتمال المصادقة والبيانات، من دون ظهور خطأ JavaScript في السجل. يغطي تحقق الخادم واختبارات الوحدات حالة العرض فقط وحالة الإدارة لكل من الموارد البشرية والعلاقات الحكومية.
