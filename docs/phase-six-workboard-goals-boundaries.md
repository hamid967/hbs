# دفعة المرحلة السادسة — صندوق العمل والأهداف الداخلية

## المنفذ

يعرض صندوق العمل الموحد الآن أهداف الحساب الداخلية غير الملغاة، مع حالة التقدم الحالية فقط. تستدعي الخوادم الأهداف باستخدام معرف الشركة ومعرف المستخدم من سياق الجلسة، لذلك لا يطّلع المستخدم على أهداف زميل أو فريق أو شركة أخرى. يبقى صندوق العمل رابطاً للمتابعة ولا يسمح بتعديل الهدف مباشرة.

يجمع الصندوق أيضاً الإشعارات والمهام المخولة وتعيينات التدريب والأهداف الشخصية، من دون تبديل نطاقات الوصول الحالية. تبقى إدارة العناوين والتقدم وروابط التدريب في صفحة الأهداف المقيدة بـHR والمسؤول.

## الحدود المتعمدة

لا يحول هذا العرض الأهداف إلى تقييم رسمي أو قرار أو حافز أو خصم. لا تظهر أهداف الآخرين للمدير أو المستخدم، ولا تُرسل تذكيرات أو إشعارات تلقائية في هذه الدفعة.

## دليل التحقق

نجح `pnpm check`، ونجح `pnpm test` بعدد 131 اختباراً عبر 37 ملف اختبار، ونجح `pnpm build`. يثبت اختبار صندوق العمل استدعاء الأهداف بمعرف الشركة وهوية المستخدم نفسها، إلى جانب الإشعارات والتدريب الشخصي.
