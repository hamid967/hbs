# دفعة المرحلة الثالثة — العقود والوثائق

## المنفذ

تضيف هذه الدفعة سجلات عقود تشغيلية وبيانات وصفية لوثائق الموظفين ضمن الشركة. تُحفظ بايتات الملفات في التخزين المخصص، بينما تبقى قاعدة البيانات مقتصرة على مفتاح التخزين والاسم والنوع والحجم والارتباط الاختياري بسجل عقد. تدعم المعاينة المحلية قبل الحفظ ملفات PDF وPNG وJPEG فقط، بحد أقصى خمسة ميغابايت للملف.

يقتصر الوصول إلى صفحة العقود والوثائق وإجراءاتها على HR والمسؤول. تتحقق الخوادم من الشركة والموظف والعقد المرتبط، ولا تُنشئ روابط العرض إلا من وثائق تعود للشركة الحالية. تسجل العملية حدثاً موجزاً في دورة حياة الموظف دون اسم ملف أو محتوى أو بيانات حساسة.

## الحدود المتعمدة

سجل العقد هنا إداري تشغيلي، وليس عقداً قانونياً أو قالباً قانونياً أو توقيعاً إلكترونياً. لا تشمل الدفعة إصدار نصوص عقود، أو توقيعاً، أو تدقيق صلاحية قانونية، أو رواتب، أو بيانات بنكية. قبل توسيع النطاق يلزم اعتماد سياسة للاحتفاظ بالمرفقات، والتصنيف، وحقوق الوصول، ومسار توقيع إن لزم.

## دليل التحقق

نجح `pnpm check`، ونجح `pnpm test` بعدد 123 اختباراً عبر 35 ملف اختبار. شمل التحقق عزل الشركة، ومنع المدير والموظف غير المخول، وحصر أنواع الملفات القابلة للمعاينة، وبناء الصفحة في الواجهة العربية.
