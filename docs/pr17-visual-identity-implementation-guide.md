**الفرع:** `feat/premium-visual-identity`  
**طلب المراجعة:** [PR #17](https://github.com/hamid967/hbs/pull/17)

## الهوية داخل مساحة العمل

لا تقتصر الدفعة على التسويق. حدّث `client/src/pages/Home.tsx` الإنترو الداخلي والبطاقة التشغيلية من دون أرقام ثابتة، حيث تقرأ بطاقة الإجازات والمصروفات من استعلام التقرير الحالي وتعرض `—` أو حالة ملائمة عند غياب البيانات. كما يعيد `client/src/components/DashboardLayout.tsx` تلوين شاشة الدخول، الشريط الجانبي، الشريط العلوي وعناصر التنقل فقط؛ لا يغير شروط إظهار عناصر القائمة أو حالات الحساب أو استدعاءات المصادقة.

## تشغيل معاينة محلية تفاعلية

استخدم أوامر GitHub التالية للحصول على الفرع نفسه، ثم ابدأ معاينة واجهة Vite. هذه المعاينة مناسبة لفحص التصميم والتنقلات المرئية والإنترو وقائمة الهاتف والتغييرات الفورية في CSS/React.

```bash
gh repo clone hamid967/hbs
cd hbs
gh pr checkout 17
pnpm install --frozen-lockfile
pnpm exec vite --host 127.0.0.1 --port 3101
```

بعد ظهور رابط Vite، افتح:

```text
http://127.0.0.1:3101/
```

| ما يمكن مراجعته تفاعلياً | ما لا تثبته هذه المعاينة وحدها |
|---|---|
| الإنترو، عناصر التنقل، قائمة الهاتف، الأقسام، التدرجات، الأصول، وحالات التركيز والتحريك. | جلسة OAuth حقيقية أو نتائج tRPC محمية أو أرقام التقارير الخاصة بالشركة. |
| الانتقال محلياً إلى `/app` و`/request-demo` كواجهة عميل. | قبول OAuth الحي أو أي قرار موافقة في نظام الإنتاج. |

### قيد المعاينة المتكاملة الحالي

يفشل الأمر `pnpm dev` حالياً في هذا المرجع بسبب صياغة المسار العام `app.use("*")` في `server/_core/vite.ts`، إذ إن الاعتماد الحالي يستخدم Express 5 الذي لا يقبل هذه الصياغة. هذا القيد سابق على تغييرات PR #17 وليس جزءاً من الهوية البصرية. لا تعدّل الملف ضمن PR #17 لغرض تشغيل المعاينة؛ افصل إصلاح توافق Express في طلب مراجعة مستقل مع اختبارات خادم، ثم استخدم `PORT=3101 pnpm dev` للمعاينة المتكاملة.
