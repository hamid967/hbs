# تقييم دمج ملفات التوظيف المرفقة

## المحتوى المستلم

احتوى الأرشيف على ملف واجهة باسم `Recruitment.tsx` وملف تعديل باسم `recruitment-module.patch`. كلاهما يقدم واجهة عربية للتوظيف، إلا أنهما يمثلان نموذجاً أولياً بحالة محلية وبيانات معاينة ثابتة.

## قرار الدمج

حُفظت النسختان كما وردتا في هذا المسار المرجعي للمشروع، ولم تُسجلا كمسار تشغيلي أو تُطبقا فوق وحدة التوظيف الحية. الوحدة التشغيلية الحالية هي `RecruitmentOnboarding.tsx`، وهي متصلة بإجراءات tRPC، وتعزل الشركة، وتدعم الشواغر والمرشحين والمقابلات والعروض الداخلية ومهام وقوالب التهيئة.

| الملف | القرار | المبرر |
|---|---|---|
| `Recruitment.mock-reference.tsx` | حُفظ مرجعياً فقط | يستخدم بيانات مرشحين وشواغر محلية ثابتة ويغير الحالة داخل المتصفح، لذلك لا يصلح بديلاً للوحدة الحية. |
| `recruitment-module.reference.patch` | حُفظ مرجعياً فقط | يستهدف نسخة أقدم من المسارات والتنقل، ويضيف مساراً يتعارض مع مسار التوظيف الحي الحالي. |

## عناصر يمكن الاستلهام منها لاحقاً

يصلح تنظيم أعمدة مسار المرشحين ومؤشرات العدّ في الملف المرفق كمرجع تجربة فقط. أي اعتماد مستقبلي لها يجب أن يقرأ بيانات التوظيف الحية عبر tRPC، ويخضع لصلاحيات HR/Admin وعزل `companyId`، ولا ينشئ بيانات معاينة أو مرشحين افتراضيين.
