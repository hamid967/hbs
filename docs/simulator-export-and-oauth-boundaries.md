# تجربة المحاكي وتصدير الأهداف وحدود OAuth

## المنفذ

يعرض محاكي الموافقات حالة معالجة مرئية قصيرة عند الانتقال بين المراحل، ورسالة نجاح عند اكتمال المسار. تظل جميع هذه الحالات ضمن واجهة المحاكاة ولا تُنشئ طلبات أو قرارات أو جلسات.

تتيح لوحة الأهداف لـHR والمسؤول تنزيل صفوف الأهداف الظاهرة بعد التصفية الحالية إلى CSV أو PDF. يبنى الملف من نفس أهداف الشركة التي حملتها لوحة HR/Admin، مع تطبيق القسم وتاريخ الهدف قبل التصدير. لا يستدعي التصدير واجهة جديدة ولا يتجاوز العزل الذي يفرضه `goals.overview`.

## OAuth والقبول الحي

يبقى مسار OAuth الحالي هو المسار الوحيد لإنشاء الجلسة الحية. لا يمكن للواجهة أو المحاكي تفعيل حسابات متعددة أو توليد جلسات موظف ومدير ووحدة مختصة أو تجاوز موافقة المستخدم وتسجيل الدخول. القبول الحي يظل دليلاً منفصلاً يتطلب ثلاثة مستخدمين مفعّلين وجلسات مستقلة داخل الشركة نفسها.

## دليل التحقق

نجح `pnpm check`، ونجح `pnpm test` بعدد 133 اختباراً عبر 38 ملف اختبار، ونجح `pnpm build`. يظل تحذير حجم بعض حزم البناء دين أداء معروفاً وليس فشل بناء.
